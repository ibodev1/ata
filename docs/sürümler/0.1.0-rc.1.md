# Ata Dil 0.1.0-rc.1

Ata Dil'in ilk yayın adayıdır. 0.1.0 öncesinde deneysel bir hobi ve öğrenme dilidir; uyumluluk garantisi verilmez.

Mevcut dil Unicode/Türkçe tanımlayıcılar, statik tip denetimi, lexical kapsam, işlevler/özyineleme, listeler, nominal yapılar, payload taşımayan seçenekler ve exhaustive eşleştirme sunar. İsteğe bağlı tip daraltma, yazı yerleştirme, döngüler ve küçük bir yerleşik işlev kümesi vardır. Bu aşamada yeni dil özelliği eklenmedi.

Standalone binary hedefleri Windows x64, Linux x64, macOS x64 ve macOS arm64'tür. Yayın hazırlığı dört binary, SHA256SUMS.txt ve PowerShell/sh kurulum-kaldırma scriptlerini üretir. Installer SHA-256 doğrulaması başarısızsa kurulumu durdurur. Windows'ta kullanıcı düzeyinde `%LOCALAPPDATA%\Ata\bin`, Unix/macOS'ta `$HOME/.local/bin` kullanılır; admin/sudo istenmez. Unix shell ayar dosyaları değiştirilmez.

**Bu yayın adayı kod imzalı değildir.** Windows Authenticode, Apple Developer ID ve macOS notarization yoktur. SHA-256 tutarlılık kontrolü kod imzasının yerine geçmez. Installer SmartScreen, Gatekeeper, quarantine veya PowerShell execution policy ayarlarını değiştirmez.

Bilinen kısıtlar: modül/paket sistemi, payload'lı seçenekler, alan/liste mutasyonu ve async yoktur. Windows arm64 ve Linux arm64 installer tarafından açık hatayla reddedilir.

`release.yml` manuel tetiklemede yalnızca Actions artifact üretir. İleride tag tetiklemesi paket sürümüyle tam eşleşirse ve kalite/smoke kapıları geçerse mevcut remote tag için prerelease yayınlayabilir; otomatik tag oluşturmaz.
