# Ata Dil 0.1.0-rc.2

RC.1 Windows installer uyumluluk hatası düzeltildi: mimari algılama artık tek bir .NET `OSArchitecture` özelliğine bağımlı değildir. Windows PowerShell 5.1 ve PowerShell 7+ üzerinde CIM, WMI, korumalı RuntimeInformation ve son olarak ortam değişkenleri sırasıyla değerlendirilir. Yalnızca Windows x64 kabul edilir; ARM64, x86 ve bilinmeyen mimariler reddedilir.

Her iki PowerShell sürümünde bağımsız mimari regresyonu, ağ kullanmadan release URL/HTTP hata testleri ve geçici dizinde gerçek binary kurulum/kaldırma doğrulanır. SHA-256 doğrulaması zorunludur; kullanıcı PATH'i smoke testlerinde değiştirilmez.

Dil semantiğinde veya desteklenen standalone platformlarda değişiklik yoktur. Bu sürüm hâlâ deneysel bir yayın adayıdır. Binary'ler kod imzalı değildir; Windows Authenticode, Apple Developer ID signing ve macOS notarization yoktur. Checksum, kod imzasının yerini tutmaz.
