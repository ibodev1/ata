# Ata Dil 0.1.0

Ata Dil'in ilk kararlı geliştirme sürümü.

## Kurulum

Windows:

```powershell
irm https://github.com/ibodev1/ata/releases/latest/download/kur.ps1 | iex
ata sürüm
```

Linux/macOS:

```bash
curl -fsSL https://github.com/ibodev1/ata/releases/latest/download/kur.sh | sh
```

`~/.local/bin` PATH'inizde yoksa mevcut oturumda ekleyin; installer shell ayarlarını değiştirmez:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

Hızlı komutlar installer scriptini doğrudan çalıştırır; isterseniz önce indirip inceleyebilirsiniz. Installer binary'yi SHA-256 ile doğrular.

## Öne çıkanlar

- Türkçe sözdizimi, Unicode adlar ve statik tip denetimi.
- İşlevler, listeler, yapılar, seçenekler ve bütün üyeleri kapsayan `eşleştir`.
- İsteğe bağlı değerler ve akışa duyarlı daraltma; güvenli dönüşüm/liste erişimi.
- Standalone binary'ler; kullanıcıda Bun gerekmez.

## Desteklenen sistemler

Windows x64, Linux x64, macOS Intel x64 ve macOS Apple Silicon arm64. Windows ARM64 ve Linux ARM64 desteklenmiyor.

## Notlar

- Binary'ler kod imzalı değildir; macOS notarization yoktur. SHA-256 kod imzası değildir; güvenlik ayarları atlatılmaz.
