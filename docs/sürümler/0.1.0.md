# Ata Dil 0.1.0

Ata Dil'in ilk kararlı geliştirme sürümü için final kaynak hazırlığıdır; `v0.1.0` tag'i ve GitHub Release henüz oluşturulmadı. Dil hâlâ erken aşamadadır; bu sürüm 1.0 olgunluğu veya sözdiziminin sonsuza kadar korunacağı garantisini taşımaz. Aşama 15 yeni dil özelliği eklemez.

## Mevcut dil

- Türkçe sözdizimi, Unicode adlar, sabit ve değiştirilebilir bağlar; statik `sayı`, `yazı`, `mantık` tipleri.
- `yok`, isteğe bağlı `T?` tipleri ve akışa duyarlı daraltma. `hiç` yalnızca doğrudan çıplak işlev dönüş tipidir; değer veya bileşik tip olarak kullanılamaz.
- Homojen listeler, nominal yapılar, payload taşımayan nominal seçenekler ve bütün üyeleri kapsayan `eşleştir`.
- İşlevler, özyineleme, lexical kapsam, koşullar, `iken` ve liste döngüleri, yazı yerleştirme.
- Temel yerleşikler, senkron girdi, güvenli sayı/mantık dönüşümü ve isteğe bağlı liste erişimi; `yardım`, `sürüm`, `denetle`, `çalıştır` komutları.

## Dağıtım ve güvenlik

Standalone binary'ler Windows x64, Linux x64, macOS Intel x64 ve macOS arm64 içindir; kullanıcıda Bun gerekmez. Windows arm64 ve Linux arm64 installer tarafından açık hatayla reddedilir.

Release assetleri dört binary, `SHA256SUMS.txt`, `kur.ps1`, `kur.sh`, `kaldir.ps1`, `kaldir.sh` dosyalarıdır. SHA-256 manifesti sekiz binary/script assetini sabit alfabetik sırayla kapsar. Installer binary checksum'u doğrulanmadan kurmaz; yerel dosya modu da checksum ister.

Kurulum kullanıcı düzeyindedir: Windows `%LOCALAPPDATA%\Ata\bin`, Unix/macOS `$HOME/.local/bin`. Windows yalnızca User PATH'e eksik kaydı ekler; Unix shell ayarlarını değiştirmez. Uninstaller kayıtlı Ata dosyalarını kaldırır; yabancı veya değiştirilmiş dosyaları korur.

Windows Authenticode, Apple Developer ID imzası ve macOS notarization **yoktur**. SHA-256 kod imzasının yerine geçmez. SmartScreen, Gatekeeper, quarantine veya PowerShell execution policy atlatılmaz. İmzasız binary güvenlik uyarıları verebilir.

## Kısıtlar ve yayın durumu

Modül/import ve paket sistemi, alan/liste mutasyonu, payload'lı seçenekler, async ve concurrency yoktur. Proje deneysel hobi dili olarak geliştirilmektedir.

Repository hâlâ PRIVATE; RC.3 private prerelease olarak yayımlandı ve dört native artifact/yerel installer doğrulaması geçti. Anonim internet installer doğrulaması henüz yapılmadı. Final yayın öncesinde yeni commit için uzak CI ve manuel artifact doğrulaması, Public geçiş ve anonim RC.3 Windows/Linux kurulumu tamamlanmalıdır. [Yayın kontrol listesi](../0.1.0-yayın-kontrol-listesi.md) tamamlanmadan final tag/release oluşturulmaz.
