# Ata Dil 0.1.0-rc.3

0.1.0 öncesi son stabilizasyon için hazırlanmış, henüz yayımlanmamış iç adaydır. Yeni dil özelliği yok; feature freeze sürüyor.

Bir yayın hatası düzeltildi: release workflow bütün tag'leri koşulsuz prerelease işaretliyordu. Artık doğrulanmış paket sürümünden RC/dev ile final ayrımı yapılır. RC/dev `--prerelease --latest=false`, final `--latest` kullanır; `--verify-tag`, tag/sürüm eşleşmesi, en düşük token izinleri ve manuel çalışmada yalnızca artifact üretimi korunur. Gerçek workflow shell adımı sahte `gh` sınırıyla ağ/yayın olmadan regresyon testine alınmıştır.

Ek kontroller keyword sınırları/NFC, Unicode/CRLF tanı aralıkları, hatalı ve sabit seed'li parser corpus, makul sözdizimi derinliği, nominal tipler, nested daraltma, değerlendirme sırası, 255/256/257 çağrı sınırı, liste/dönüşüm ve eşleştirme davranışlarını kapsar. CLI/binary sınırları boş/dizin/bozuk UTF-8 kaynaklar, kabuk karakterli yollar, stdin EOF/boş satır/emoji/ardışık girdiyle güçlendirildi. Installer kontrolleri değiştirilmiş kurulu binary korunumu, boşluklu HOME, temp temizliği ve `chmod 755` çağrısını kapsar.

Lexer, parser, analiz, runtime, CLI, installer, tanı kataloğu, bağımlılıklar, CI/release ve belgeler karşılaştırıldı. Dört platform asseti, sekiz dosyanın alfabetik SHA-256 manifesti ve Windows PowerShell 5.1/7+ yerel install/upgrade/run/uninstall doğrulaması mevcuttur. Windows üzerindeki sh testleri platform sınırını taklit eder; gerçek Linux/macOS binary smoke başarısı iddia edilmez. Uzak CI/release workflow bu commit için çalıştırılmadı.

Bir tam kontrol çalıştırmasında mevcut PowerShell 5.1 HTTP mock testi ikinci isteğe ulaşmadı. Dört tekrarın 16 HTTP senaryosunda yeniden oluşmadı; kök neden doğrulanmadığı için düzeltildiği iddia edilmez. Başarısız URL beklentisi artık subprocess stderr mesajını da gösterir; uzak Windows CI sonucu ayrıca gözlemlenmelidir.

Repository PRIVATE kalır. Mevcut yayımlanmış private RC `v0.1.0-rc.2`; anonim internet installer public geçiş sonrası tekrar denenmelidir. Private assetlerin anonim 404 yanıtı installer hatası değildir. Token/PAT veya `gh` installer bağımlılığı eklenmedi. Binary'ler kod imzalı değildir; notarization yoktur, güvenlik mekanizmaları atlatılmaz.

## Karar bekleyen dil davranışı

`hiç` ile `yok` doğrudan kullanımda ayrı kalır; fakat bileşik `hiç` tiplerinin izinleri mevcut sözleşmede açık değildir. Şu program analizden geçer, yazdırmada iç çalışma zamanı tanısı `ATA5005` üretir:

```text
işlev boş(): hiç {}
sabit x: hiç? = boş()
x yazdır
```

`[boş()] yazdır` ise `[hiç]` gösterir. `hiç?` ve `liste<hiç>` türlerinin yasaklanması ya da gösterim/erişim kurallarının tanımlanması dil tasarımı kararıdır; bu aşamada semantik değiştirilmedi. Final yayın öncesi bu tutarsızlığın kararı ve uygulanacak çözüm gereklidir.

Modül/paket sistemi, payload'lı seçenek, alan/liste mutasyonu ve async yoktur. Public geçiş, anonim RC testi ve final yayın sırası [yayın kontrol listesinde](../0.1.0-yayın-kontrol-listesi.md) tutulur.
