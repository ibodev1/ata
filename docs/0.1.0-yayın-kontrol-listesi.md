# 0.1.0 yayın kontrol listesi

Mevcut kaynak sürümü `0.1.0-rc.3`, yayımlanmamış iç adaydır. Repository PRIVATE; mevcut private yayın `v0.1.0-rc.2`. Bu liste insan tarafından final öncesi tamamlanır; aşağıdaki gelecek yayın adımları Aşama 12 kapsamında yürütülmedi.

## Yerel stabilizasyon

- [x] Feature freeze altında lexer/parser/analiz/runtime/CLI/installer/release ve belge denetimi tamamlandı.
- [x] Yerel `check`, `release:prepare`, `check:release` başarılı; dört RC.3 binary ve dört installer/uninstaller mevcut.
- [x] RC.3 SHA-256 manifesti sekiz asseti sabit alfabetik sırada kapsıyor; bağımsız hesaplamayla doğrulandı.
- [x] Windows PowerShell 5.1/7+ yerel install/upgrade/run/uninstall gerçek User PATH değişmeden geçti.
- [x] sh syntax, platform sınırı, boşluklu HOME, checksum/temp cleanup ve dosya korunumu Windows/Git Bash üzerinde test edildi.
- [ ] Bileşik `hiç` tipleri (`hiç?`, `liste<hiç>`) hakkında dil kararı verildi ve tutarsızlık giderildi: `hiç?` yazdırma analizden geçip `ATA5005` üretebiliyor. [Reproducer ve bağlam](sürümler/0.1.0-rc.3.md).

## Public geçiş ve final yayın

Sıra: **son audit → repository Public → mevcut RC ile anonim installer doğrulama → final sürüm commit'i → v0.1.0 tag → final release**. Son audit'te karar bekleyen konu çözüldükten sonra kalite ve release kapıları yeniden çalıştırılmalı.

- [ ] Main CI yeşil; son stabilizasyon commit'i üzerinde uzak sonuç gözlemlendi.
- [ ] Manuel release artifact workflow yeşil; dokuz dosya indirildi ve incelendi. Manuel çalıştırma public release üretmiyor.
- [ ] Repository public yapıldı.
- [ ] Mevcut RC ile anonim Windows internet install/run/uninstall geçti; PowerShell 5.1 ve 7+ doğrulandı.
- [ ] Mevcut RC ile anonim Linux installer geçti veya gerçek Ubuntu CI karşılığı gözlemlendi.
- [ ] macOS gerçek smoke ve unsigned/Gatekeeper deneyimi değerlendirildi; başarısı gözlemlenmeden iddia edilmedi.
- [ ] Kaynak sürümü `0.1.0`; final yayın notu ve installer varsayılanları güncellendi, final kalite/release kapıları yeşil.
- [ ] Final commit incelendi, mevcut remote tag olarak yalnızca bu commit için `v0.1.0` oluşturuldu.
- [ ] Final release workflow yeşil; tag/sürüm eşleşiyor, `--verify-tag` kullanılıyor, final prerelease değil.
- [ ] Final release assetleri tam: dört binary, `SHA256SUMS.txt`, `kur.ps1`, `kur.sh`, `kaldir.ps1`, `kaldir.sh`.
- [ ] İndirilen final assetlerin SHA-256 değerleri bağımsız doğrulandı.
- [ ] Public final Windows install/run/upgrade/uninstall geçti; PATH ve yabancı/değiştirilmiş dosya korunumu doğrulandı.
- [ ] README public kurulum komutları gerçek yayınla aktif; kod imzası/notarization bulunmadığı doğru belirtiliyor.

Signing bu aşamanın kapsamı değildir; SHA-256 kod imzası yerine geçmez. Private 404 için token/PAT/gh eklenmez. Uzak CI, public geçiş, anonim installer ve final yayın tamamlanmadan final hazır olarak işaretlenmez.
