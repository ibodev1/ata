# 0.1.0 yayın kontrol listesi

Mevcut kaynak sürümü `0.1.0-rc.3`, yayımlanmamış iç adaydır. Repository PRIVATE; mevcut private yayın `v0.1.0-rc.2`. Bu liste insan tarafından final öncesi tamamlanır; aşağıdaki gelecek yayın adımları Aşama 12 kapsamında yürütülmedi.

- [x] Feature freeze altında lexer/parser/analiz/runtime/CLI/installer/release ve belge denetimi tamamlandı.
- [x] Yerel `check`, `release:prepare`, `check:release` başarılı; dört RC.3 binary ve dört installer/uninstaller mevcut.
- [x] RC.3 SHA-256 manifesti sekiz asseti sabit alfabetik sırada kapsıyor; bağımsız hesaplamayla doğrulandı.
- [x] Windows PowerShell 5.1/7+ yerel install/upgrade/run/uninstall gerçek User PATH değişmeden geçti.
- [x] sh syntax, platform sınırı, boşluklu HOME, checksum/temp cleanup ve dosya korunumu Windows/Git Bash üzerinde test edildi.
- [x] Aşama 13: `hiç` yalnızca çıplak işlev dönüş tipi; değer/bileşik tipleri ve bağlama/liste elemanı olarak çağrı sonucu statik reddediliyor. `ATA4034` ve regresyonlar ile type-safety blocker kapatıldı. [Düzeltme ve bağlam](sürümler/0.1.0-rc.3.md).

## Native release artifact kapısı (Aşama 14)

`release.yml` tek Ubuntu build artifact'ini dört bağımsız native runner'a indirir. Her job native SHA-256 kontrolünden sonra sürüm/yardım/denetle/çalıştır ve local-file install/uninstall smoke yapar. Tag publish'i build ve dört doğrulamanın tamamına bağlıdır; manuel çalışmada publish skipped kalır.

Yeni workflow henüz uzak ortamda çalıştırılmadı; aşağıdaki maddeler uzak sonuç gözlemlenene kadar işaretlenmez. macOS native smoke, tarayıcıdan public indirme sonrası unsigned/Gatekeeper deneyiminin doğrulandığı anlamına gelmez.

- [ ] Windows x64 release artifact native smoke (`windows-latest`).
- [ ] Linux x64 release artifact native smoke (`ubuntu-24.04`).
- [ ] macOS x64 release artifact native smoke (`macos-15-intel`).
- [ ] macOS arm64 release artifact native smoke (`macos-15`).

- [ ] Main CI yeşil; son stabilizasyon commit'i üzerinde uzak sonuç gözlemlendi.

- [ ] Repository public yapıldı.
