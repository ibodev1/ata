## Public geçiş ve final yayın: açık operasyonlar

Sıra: **final hazırlığı push → yeni commit CI yeşil → manuel 0.1.0 artifact/dört native doğrulama → repository Public → anonim RC.3 Windows ve Linux/WSL kurulumları → final checklist incelemesi → v0.1.0 tag push → dört native doğrulama → final publish → final asset/smoke**.

- [ ] Final hazırlık commit'i push edildi; bu commit'in main CI ve Windows installer CI sonuçları yeşil.
- [ ] Manuel `0.1.0` candidate workflow başarılı; dokuz dosya incelendi, dört native job yeşil, publish skipped.
- [ ] Repository Public yapıldı. LICENSE kararı kullanıcıya bırakıldı; Public geçiş öncesi kullanıcı karar verebilir, teknik pipeline bununla değiştirilmez.
